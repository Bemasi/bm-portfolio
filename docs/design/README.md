# Diseño del porfolio

Aquí vive todo lo que no es código: por qué el sitio es como es, qué se decidió
y qué se descartó, y los bocetos por los que fuimos pasando.

```
docs/design/
├── README.md                  este archivo
├── decisiones.md              registro de decisiones, la más reciente arriba
├── contenido-proyectos.md     los campos con los que se cuenta cada proyecto
└── bocetos/                   prototipos, uno por archivo, con fecha en el nombre
```

**Para añadir una decisión:** una entrada nueva en `decisiones.md` con fecha, qué se
decide, por qué, y qué se descartó. Si una decisión sustituye a otra anterior, se marca
la vieja como superada en lugar de borrarla — el porqué de un cambio de opinión vale
tanto como la decisión.

**Para añadir un boceto:** un archivo en `bocetos/` con el formato `AAAA-MM-DD-nombre.html`.
Son desechables: se miran, se decide, y se quedan como registro. Ninguno es código del
proyecto real.
